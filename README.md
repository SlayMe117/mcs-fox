# MCS Fox

Android-приложение для прямого подключения к станциям **MCS network / Niagara**
по протоколу Fox (TCP, порт 1911) — без брокера, MQTT и oBIX.

Интерфейс — HTML/JS в WebView, сетевая часть — нативный Java-клиент
(`FoxClient.java`): `hello`, вход по **SCRAM-SHA-256**, обход дерева станции
(**discover**). Протокол восстановлен по дампу Workbench 3.8.111 ↔ Station 3.8.401.

## Сборка APK

APK собирается автоматически на GitHub Actions при каждом push
(вкладка **Actions** → последний запуск → артефакт **mcs-fox-debug-apk**).
Скачанный `app-debug.apk` установить на телефон (разрешить установку из
неизвестных источников). Android 8.0+.

## Использование

Телефон должен быть в одной сети со станцией. В приложении: адрес станции,
порт (1911), пользователь, пароль, глубина обхода → «Подключиться».
